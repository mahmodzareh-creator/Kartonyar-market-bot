# KartonYarMarketBot

ربات جامع کارتن‌یار برای ثبت آگهی، جستجو، بانک شرکت‌ها، محصولات و خدمات، گروه‌ها و پشتیبانی.

## اجرا روی Render
Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Environment Variable:
`BOT_TOKEN` = توکن ربات BotFather

توکن را داخل GitHub قرار ندهید.
